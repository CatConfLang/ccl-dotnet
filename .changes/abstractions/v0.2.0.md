## v0.2.0 - 2026-05-02


### Added

- Add `ICclParser.BuildModel(string)` for the canonical CCL data model — the recursive `Map<string, Model>` shape (no scalar leaves, duplicate keys merge). Peer to `BuildHierarchy`. See https://catconflang.com/reference/functions/#build_model.

### Changed

- **Breaking:** `ICclParser` gains a required `BuildModel` member. Existing implementations must add it (a `throw new NotImplementedException()` is acceptable for impls not yet supporting the canonical model).
